# Procurement paperwork

Drafts a district can start from when it reviews Live Minutes. They ship with the server, so district
IT, college IT, and the platform owner can download them from the IT console or Platform dashboard under
Reports. Each one says what still needs the district's own review.

| Document | File | What it is |
|---|---|---|
| HECVAT Lite answers | [server/app/procurement/hecvat-lite.md](../server/app/procurement/hecvat-lite.md) | Answers for the EDUCAUSE Higher Education Community Vendor Assessment Toolkit, Lite version, based on the software as built and the current pilot. |
| Accessibility conformance report | [server/app/procurement/vpat-acr.md](../server/app/procurement/vpat-acr.md) | A VPAT 2.5 style report against WCAG 2.1 A and AA from vendor checks, with planned fixes. Needs an outside audit. |
| FERPA data protection agreement | [server/app/procurement/ferpa-dpa.md](../server/app/procurement/ferpa-dpa.md) | A template agreement with school official, no sale, breach notice, export, and deletion terms. For district counsel. |
| Subprocessors and data flow | [server/app/procurement/subprocessors.md](../server/app/procurement/subprocessors.md) | Every outside service that handles data and how meeting text moves through the system. |

Keep these current with each release: test counts, new subprocessors, and anything that changes the
security answers.
